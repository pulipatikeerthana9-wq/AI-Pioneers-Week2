This report presents a supervised machine-learning comparison covering both regression and classification. The experiments use two datasets distributed with scikit-learn so that the analysis can be reproduced without downloading external files. For regression, the Diabetes dataset contains 442 observations and 10 input features. Linear Regression, a five-neighbor K-Nearest Neighbors model, and Random Forest Regression were trained to predict the dataset’s quantitative disease-progression target. For classification, the Breast Cancer Wisconsin dataset contains 569 observations and 30 features. Logistic Regression, a Decision Tree, five-neighbor K-Nearest Neighbors, and Random Forest were evaluated to distinguish malignant from benign cases. Malignant cases were explicitly defined as the positive class so that precision, recall, F1-score, and ROC-AUC have a clear interpretation.

Each experiment used an 80/20 train/test split with a fixed random seed of 42. The classification split was stratified to preserve the class proportions. Standardization was included inside pipelines for scale-sensitive models and was fitted using training data only; the held-out test data were reserved for evaluation. Regression was assessed using MAE, RMSE, and R-squared, while classification was assessed using accuracy, malignant-class precision, recall, F1-score, and ROC-AUC. The report includes the measured results, a comparison of model strengths and trade-offs, and limitations of using one holdout split and simple model settings.

In the regression experiment, K-Nearest Neighbors produced the lowest MAE (42.78), while Linear Regression had the lowest RMSE (53.85) and highest R-squared (0.453). The values are close, so the evidence does not support claiming a universally superior model. In classification, Logistic Regression and Random Forest tied on accuracy at 96.49%. Logistic Regression achieved higher malignant recall (92.86% versus 90.48%) and F1-score (0.951 versus 0.950); Random Forest achieved higher malignant precision (1.000 versus 0.975) on this test split. These differences illustrate why a single accuracy value is not enough to compare classifiers, particularly when the cost of missed positive cases matters.

The code, dependency list, run instructions, metadata, and metric CSV files are included with the report. Results are specific to these benchmark datasets and this fixed split. They are not clinical guidance, do not establish performance on new populations, and should not be treated as a guarantee of real-world performance. No hyperparameter search or cross-validation was performed. The analysis focuses on reproducibility, appropriate metrics, and evidence-based interpretation rather than presenting the scores as universal conclusions.
